# First Person Interaction Prototype

A Unity 6 prototype created as part of a Unity Developer internship assignment.

## Features
- First-person camera
- WASD movement
- Sprint
- Jump
- Crouch
- Raycast-based interaction system
- Interactive door
- "Press E to Interact" UI prompt
- Clean and modular C# architecture

## Technologies Used
- Unity 6 (URP)
- C#
- Character Controller
- TextMeshPro

## Controls
- W A S D - Move
- Mouse - Look Around
- Left Shift - Sprint
- Space - Jump
- Left Ctrl - Crouch
- E - Interact
